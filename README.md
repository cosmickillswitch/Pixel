# Pixel Puppets 🎭

Draw cute pixel puppets, drag them onto a little pixel world, act them out with a controller, and record each puppet on its own timeline track to make tiny pixel-art movies. Built for the AYN Thor, but it works in any modern browser.

## Put it on GitHub Pages

1. Create a new repository (for example `pixel-puppets`).
2. Upload everything in this folder: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png` and this README.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, pick `main` and `/ (root)`, then save.
4. After a minute the app is live at `https://<your-username>.github.io/pixel-puppets/`.

## Install on Android

Open the Pages link in Chrome, open the ⋮ menu, and choose **Add to Home screen** (or **Install app**). It opens fullscreen and works offline.

To update the app later, upload the new `index.html` over the old one. The installed app picks up the change the next time you open it (sometimes the time after).

## Controls

| Control | Action |
|---|---|
| D-pad / left stick | Walk |
| Top face button (△ / Y) | Nod head |
| Left face button (□ / X) | Left arm |
| Right face button (○ / B) | Right arm |
| Bottom face button (✕ / A) | Hop |
| L2 / R2 | Change face / change prop |
| L1 / R1 | Switch puppet |
| Start / Select | Record / Play |

On a keyboard: WASD or arrows walk · I head · J/L arms · K hop · U face · O prop · Q/E switch · R record · Space play.

Your work autosaves in the browser. Use **Scene → Save file** to keep a copy or move a project between devices.
